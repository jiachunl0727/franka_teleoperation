# OSCBF dynamics reference

`oscbf_reference.txt` contains q, dq, column-major M, c and g for 64 states:
32 recorded commissioning states and 32 deterministic random configurations
(seed 20261106). Values are generated by unmodified `load_panda()` and dynamics
functions from StanfordASL/oscbf commit
`6082329f8e1d61ee8e875a63a5cd80a14d513e12`, using JAX/JAXlib 0.4.30 float64.
The test URDF is the exact upstream asset; its license/provenance are retained
in the package's `THIRD_PARTY_LICENSES` directory. Regeneration script and
validation evidence: `log/commissioning/2026-11-06-urdf-runtime/`.
