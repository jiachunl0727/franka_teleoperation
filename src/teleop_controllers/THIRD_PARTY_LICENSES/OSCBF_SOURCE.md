# OSCBF model attribution

`config/panda_oscbf.urdf` is copied without modification from StanfordASL/oscbf,
commit `6082329f8e1d61ee8e875a63a5cd80a14d513e12`, file
`oscbf/assets/franka_panda/panda.urdf`.

https://github.com/StanfordASL/oscbf/tree/6082329f8e1d61ee8e875a63a5cd80a14d513e12

The upstream MIT license is retained in `OSCBF-MIT.txt`. Its asset README traces
the URDF to https://github.com/erwincoumans/pybullet_robots/tree/master/data/franka_panda.
Upstream modifications removed package mesh paths and safety-controller entries,
locked the fingers, and corrected a fixed joint axis. No meshes are needed by
our dynamics parser. The native implementation evaluates the same rigid-body
mass/Coriolis/gravity model; reference values are generated by unmodified OSCBF.

`config/panda_umi.urdf` is a generated derivative of this unchanged base asset.
It adds the operator-supplied UMI finger mesh and measured-mass attachment model.
See `config/umi_fingers.yaml`, `scripts/generate_umi_finger_model.py` and
`docs/cbf/UMI_FINGERS_AND_OFFLINE_AVOIDANCE.md` in the workspace. The supplied
UMI STL is a separate user-provided asset; the upstream OSCBF attribution does
not assert ownership or an MIT license for that mesh.
